# Security policy

## Supported versions

Security fixes are applied to the most recent release line (`0.1.x`) and to `main`. Earlier versions do not receive retrofixes — update to the latest.

## Responsible disclosure

Report vulnerabilities **privately** to **contatopml26@gmail.com** (subject line prefixed with `[security]`). Describe the impact and a step-by-step reproduction. Allow a reasonable amount of time for a fix before disclosing it publicly; credit to the reporter is given by default, unless requested otherwise.

## Ethical use

Chaveiro includes offensive tools (`crack`, `forge`, `forge-confusion`) intended to **test systems you own or have explicit, written authorization to assess**. The purpose is defensive: proving a flaw exists in order to justify the fix.

In Brazil, unauthorized access to a computer device is a crime (Law 12.737/2012, aggravated by Law 14.155/2021). Always use it with a defined scope and authorization.
